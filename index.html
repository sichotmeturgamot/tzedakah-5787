יומן התרומות

    עדיין אין תרומות רשומות.

    חיבור לגיטהב — כדי שהנתונים לא ייאבדו
    צריך למלא פעם אחת. אחרי זה כל תרומה נשמרת לקובץ במאגר.
    1. ליצור מאגר בגיטהב ולהעלות אליו את קבצי האפליקציה, כולל donations.json
    2. בגיטהב, בתפריט הפרופיל:
      Settings → Developer settings → Personal access tokens → Tokens (classic)
    3. לחצן Generate new token (classic)
    4. שם לטוקן, למשל צדקה. לסמן רק repo
    5. להעתיק את הטוקן ולהדביק למטה. הטוקן נשמר בדפדפן הזה בלבד.
    אם המאגר ציבורי, רשימת התרומות גלויה לכל מי שנכנס למאגר. אפשר לכתוב רק ראשי תיבות בשדה «למי».
